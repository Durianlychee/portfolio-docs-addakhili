# Addakhili — Portfolio (Docs Repo)

This repo tracks the **content, notes, and release history** for my live portfolio site: **https://www.addakhili.com**.

> I build and publish with **Framer**. This repo is for documentation and visibility (commits, Issues, and a public changelog).

## Quick links
- Live site: https://www.addakhili.com
- Projects: [/projects](./projects)
- Changelog: [CHANGELOG.md](./CHANGELOG.md)

## How I update
1. Edit Markdown files in `/projects` (or create a new one).
2. Commit with a clear message (e.g., `feat: add charts section to SpaceX case study`).
3. Publish in Framer.
4. Add an entry in the changelog.
